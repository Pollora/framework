# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 13.x    | :white_check_mark: |
| < 13.0  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Pollora, please report it responsibly.

**Do not open a public issue.**

Instead, please use [GitHub Security Advisories](https://github.com/Pollora/framework/security/advisories/new) to report the vulnerability privately.

You can expect:

- An acknowledgment within **48 hours**
- A status update within **7 days**
- A fix released as a patch version as soon as possible

Thank you for helping keep Pollora secure.
